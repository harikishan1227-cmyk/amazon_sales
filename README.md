#  Amazon Sales Dashboard - Power BI

---

##  📊 Project Overview

This project presents an interactive Amazon Sales Analysis Dashboard built using Microsoft Power BI. The dashboard provides insights into product categories, ratings, discounts, pricing, and customer engagement metrics to help understand sales performance and product trends.

##  🚀 Features

### KPI Cards

* Total Products
* Total Categories
* Average Rating
* Average Discount %
  
### Visualizations

#### * Donut Chart
  * Product distribution across categories
#### * Clustered Bar Chart
  * Rating count by category
#### * Clustered Column Chart
  * Discount percentage by category
#### * Scatter Plot
  * Relationship between:
    * Discounted Price
      * Product Rating
        * Rating Count
          * Product Category
#### * 100% Stacked Bar Chart
  * Comparison of:
    * Actual Price
      * Discounted Price
        * Discount %
          * Rating Count
            * Product Rating
#### Interactive Filters
* Category Slicer
* Rating Slicer
